# English Legend X5

**LEGEND X5 - CONNECT THE WORLD** — nền tảng dạy & học tiếng Anh: soạn và giao bài bằng AI (Gemini), học sinh làm bài trực tuyến,
chấm điểm, quản lý học sinh theo lớp, lịch & điểm danh, tổng hợp theo ngày, báo cáo tháng, tổng kết cả năm, bảng vàng.

Đội ngũ: Lưu Tuyền • Mrs Lý • Trang xinh • Ngọc Hà • Đăng Thương

## Cài đặt nhanh
```
npm install
npm run setup   # gắn Firebase Realtime Database + đặt mật khẩu quản trị
npm run dev
```
Chi tiết từng bước (tạo Firebase, đưa lên GitHub + Vercel): xem `HUONG_DAN_TRUNG_TAM_MOI.md`.
